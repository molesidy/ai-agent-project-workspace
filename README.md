# ai-agents-project-workspace
A repository dedicated to storing project-level AI Agent workspace folders for different use cases, with various skills and MCP tools pre-stored inside.

## 一、添加嵌入式代码编程工作空间模板：coding_workspace

结合skills、MCP的工作流：
输入：（1）要求文件；（2）代码工程文件夹；
输出：（2）完成的代码的文本描述；

1.全程注意合理使用context-compression进行管理压缩上下文；使用claude-md-improver写外挂的上下文记录。

2.过程中使用using-superpowers、karpathy-guidelines进行流程式编程。

3.整个项目工程完成的步骤和总结，使用notemdpro输出到result.md文件当中。

其他：1.有需要的时候才会使用find-skills、skill-creator、mcp-builder；2.有需要的时候才会使用github MCP；
